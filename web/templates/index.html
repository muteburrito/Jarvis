Phase 3 - Power Features

                    

                        

                            
Scheduled folder re-indexing

                            
Watch folders for file changes and re-index modified or new files in the background.

                        

                        

                            
Multiple named workspaces

                            
Save and switch between document sets, each with its own index and chat history.

                        

                        

                            
Vector compression research

                            
Evaluate TurboQuant-style vector compression to reduce local vector-store memory use.

                        

                        

                            
Codebase map

                            
Build a repo map with files, symbols, imports, modules, and tests.

                        

                        

                            
Context picker

                            
Pin files, folders, symbols, diffs, terminal output, URLs, and documents into the next task.

                        

                        

                            
Code-aware retrieval

                            
Add code chunking, symbol metadata, exact identifier search, dependency boosting, and reranking.

                        

                        

                            
Model role profiles

                            
Split model config by role: chat, edit, apply, autocomplete, embedding, reranker, and vision.

                        

                        

                            
Frontend modularization

                            
Split the large Alpine app and template into smaller maintainable modules or partials.

                        

                    

                


                

                    
Phase 4 - Local Coding Agent

                    

                        

                            
Agent tool loop

                            
Let the model search files, inspect symbols, summarize files, fetch URLs, and ask for approval mid-task.

                        

                        

                            
Safe local command runner

                            
Run approved commands with working directory controls, timeouts, and captured output.

                        

                        

                            
Patch generation and apply flow

                            
Generate diffs, preview changes, apply approved patches, and discard per file.

                        

                        

                            
Test and fix loop

                            
Run tests, parse failures, update patches, and repeat within bounded iterations.

                        

                        

                            
Git worktree and branch support

                            
Use isolated branches or worktrees per task so multiple sessions do not overwrite each other.

                        

                        

                            
Code review mode

                            
Review a diff or branch and produce findings with severity, file, line, risk, and test gaps.

                        

                        

                            
GitHub issue and pull request flow

                            
Create tasks from issues, push branches, and draft pull requests with summaries and tests.

                        

                        

                            
Skills and project rules

                            
Load reusable local skills and repo instructions only when they are relevant.

How to use Jarvis

                
            

            


                

                    
Getting started

                    
Jarvis lets you chat with your documents using a local AI. Everything runs on your machine. No data is sent to the cloud.

                    
You can also use it as a general-purpose assistant without uploading anything.

                


                

                    
1. Upload a document

                    
Use the buttons beside the chat input to add context:

                    
    
                        
  • Paper clip selects files such as PDF, DOCX, XLSX, PPTX, images, or code files
    • 
                        
  • Folder selects and indexes files from a local folder
    • 
                        
  • Braces opens the code snippet box for code that should stay inline with your question
    • 
                        
  • URLs in normal chat are fetched and indexed automatically
    • 
                    

                


                

                    
2. Ask questions

                    
Type your question in the chat input and press Enter. The AI will:

                    
    
                        
  • Search your indexed documents for relevant content
    • 
                        
  • Answer based on what it finds, with source citations
    • 
                        
  • If no documents are loaded, it works as a general assistant
    • 
                    

                


                

                    
Model selection

                    
Jarvis chooses a small local Gemma model when CHAT_MODEL is not set:

                    
    
                        
  • gemma4:e2b for very low-end machines
    • 
                        
  • gemma4:e4b for everyone else
    • 
                    

                    
The 26b model is opt-in only. Set CHAT_MODEL before starting Jarvis if you want qwen2.5-coder:14b, gemma4:26b, or another local model.

                


                

                    
3. Research mode

                    
Click the magnifying glass button next to the chat input. It turns purple when active.

                    
In research mode, Jarvis will:

                    
    
                        
  • Generate search queries from your question
    • 
                        
  • Search the web using DuckDuckGo
    • 
                        
  • Fetch and read the top articles
    • 
                        
  • Answer with citations and links to the sources
    • 
                    

                    
No API key needed. Fetched articles are saved locally so follow-up questions are instant.

                


                

                    
4. Manage documents

                    
    
                        
  • Click the indexed count in the chat header to view indexed documents
    • 
                        
  • Hover over a document and click the trash icon to remove it
    • 
                        
  • Use Clear all in the indexed files panel to remove everything
    • 
                    

                


                

                    
Tips

                    
    
                        
  • Paste a URL directly in chat and the AI will auto-fetch it before answering
    • 
                        
  • Paste code into the code snippet box when URLs should not be fetched
    • 
                        
  • The AI adapts to your region automatically (currency, date format, etc.)
    • 
                        
  • Use Shift+Enter for a new line without sending
    • 
                        
  • Images in PDFs are described by a vision model and become searchable
    • 
                        
  • Supported files: documents, images, and any text-like source or config file. Binary files are skipped or rejected
    • 
                    

                


                

                    
Jarvis runs entirely on your machine using Ollama. Your documents and conversations never leave your computer.
