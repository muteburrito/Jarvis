How to use Jarvis

                
            

            


                

                    
Getting started

                    
Jarvis is a local AI workbench for documents, folders, images, code, web research, and day-to-day questions. It runs on your machine with Ollama, keeps chat history locally, and can work even when no files are indexed.

                    
Your usual flow is simple: add context, ask a question, focus the next prompt when needed, then use the response tools to copy, rate, fork, or continue the conversation.

                


                

                    
1. Add context

                    
Use the composer buttons beside the chat input:

                    
    
                        
  • Paper clip uploads files such as PDF, DOCX, XLSX, PPTX, images, markdown, text, logs, data files, config files, and source code
    • 
                        
  • Folder indexes a local folder recursively. Jarvis skips build output such as node_modules, bin, obj, vendor, and .git
    • 
                        
  • Braces opens the code snippet box for code that should stay inline with your question
    • 
                        
  • Paste images directly into chat to attach them to the next question
    • 
                        
  • Paste URLs in normal chat to fetch and index web pages quietly
    • 
                    

                    
Folders you index are remembered. Jarvis checks watched folders in the background and refreshes new or changed files.

                


                

                    
2. Ask questions

                    
Type a question and press Enter. Use Shift+Enter for a new line. Jarvis will:

                    
    
                        
  • Search indexed files with hybrid retrieval, semantic search plus keyword matching
    • 
                        
  • Keep generic questions in general chat even when files are indexed
    • 
                        
  • Request safe read-only project tools when a folder is active, such as file search, summaries, and text previews
    • 
                        
  • Answer based on what it finds, with source citations
    • 
                        
  • Fall back to general chat when no relevant files are indexed
    • 
                        
  • Use your browser locale, timezone, and quiet live web context for current questions when available
    • 
                    

                


                

                    
3. Focus the conversation

                    
    
                        
  • Reply to a message by using the reply button near a chat bubble. Jarvis includes that exact message as context
    • 
                        
  • @file or #file mentions focus retrieval on specific indexed files. Start typing @ or # and choose from suggestions
    • 
                        
  • Queued follow-ups let you type the next message while an answer is still streaming. Jarvis runs it automatically afterward
    • 
                    

                


                

                    
4. Research mode

                    
Open the model and mode dropdown next to the chat input, then enable Research mode when you want to see the web search process.

                    
In research mode, Jarvis will:

                    
    
                        
  • Generate search queries from your question using local date, local time, locale, and timezone
    • 
                        
  • Search the web using DuckDuckGo
    • 
                        
  • Fetch and read the top articles
    • 
                        
  • Index useful pages locally, then answer with citations and links
    • 
                    

                    
Normal chat can quietly refresh live context too. Research mode is for transparent source-heavy work where you want progress and citations visible.

                


                

                    
5. Use response tools

                    
    
                        
  • Copy response copies the assistant answer as markdown text
    • 
                        
  • Thumbs up or down saves your rating on that response
    • 
                        
  • Fork creates a new chat from the conversation up to that response, useful when you want to explore another direction
    • 
                        
  • Working time shows how long Jarvis has been generating, then keeps the final response duration
    • 
                    

                


                

                    
6. Manage indexed files

                    
    
                        
  • Click the indexed count in the chat header to view indexed documents
    • 
                        
  • Delete a single indexed file when you no longer want it in retrieval
    • 
                        
  • Use Clear all to clear the active project index, the global index, and Jarvis-owned upload copies
    • 
                        
  • External files indexed from folders are preserved on disk when you delete or clear the index
    • 
                        
  • Images are described by the vision model when available, then stored as searchable text
    • 
                    

                


                

                    
7. Workbench

                    
Open the Workbench button in the top bar to inspect local activity:

                    
    
                        
  • Task traces from chat, retrieval, research, folder indexing, and workspace map updates
    • 
                        
  • Read-only tool traces when chat searches, summarizes, or previews active-project files
    • 
                        
  • Workspace map root, file counts, package counts, tests, type breakdown, folder groups, files, and code symbols
    • 
                        
  • Useful context for codebases and regular folders with Office files, PDFs, images, logs, and data
    • 
                    

                


                

                    
Models and setup

                    
Jarvis uses Ollama locally for chat, embeddings, and optional image understanding. On Windows, the installer can bootstrap Ollama and pull required models during manual install.

                    
    
                        
  • nomic-embed-text creates embeddings for retrieval
    • 
                        
  • gemma4:e2b is selected automatically for very low-end machines
    • 
                        
  • gemma4:e4b is the default for most machines
    • 
                        
  • llava is optional and enables image descriptions
    • 
                    

                    
Use the composer dropdown to choose Gemma 4 2B, 4B, or 26B for a request. Missing dropdown models are downloaded automatically through Ollama. Thinking mode adds Gemma 4 private reasoning prompting and keeps hidden thought text out of saved chat history.

                


                

                    
Updates and desktop use

                    
    
                        
  • The desktop app is the primary installed experience
    • 
                        
  • Release builds can check GitHub Releases for updates
    • 
                        
  • Silent auto-updates keep installs fast and skip the Ollama bootstrap step
    • 
                        
  • The browser server remains useful for development and fallback testing
    • 
                    

                


                

                    
Helpful habits

                    
    
                        
  • Use @file mentions when a question must stay grounded in a specific indexed file
    • 
                        
  • Use the code snippet box for code that should not trigger URL fetching
    • 
                        
  • Use forks when a response is useful but you want to try a different next step
    • 
                        
  • Use research mode when you want visible search progress and cited web sources
    • 
                        
  • Jarvis adapts answers to your browser locale and timezone when possible
    • 
                    

                


                

                    
Jarvis is local-first. Your indexed files, embeddings, chat history, task state, and workspace maps stay on your computer. Web pages are fetched only for live context, research, or pasted URLs.
